# A360 - Core - Product Resume

Create a premium editorial resume website that can also be exported perfectly as a 2-page PDF.

This is NOT a Canva-style resume.

The objective is to create something that looks like it was designed by a Product Design team at Linear, Stripe, Vercel, Notion or Anthropic.

The design must immediately communicate:

clarity

product thinking

systems thinking

AI

modern SaaS

minimalism

premium quality

====================================================

GENERAL STYLE

====================================================

Very minimalist.

Huge amount of white space.

Perfect typography hierarchy.

Grid system.

Large margins.

No gradients.

No glassmorphism.

No flashy colors.

No unnecessary icons.

No progress bars.

No skill percentages.

No stars.

No Canva feeling.

Everything must feel intentional.

Font:

Inter

Main colors:

#0F172A

#1D4ED8

#F8FAFC

#CBD5E1

Border radius:

12px

Soft shadows only.

Use cards only where useful.

Everything must align perfectly.

====================================================

PAGE SIZE

====================================================

The page must automatically export into a beautiful A4 PDF.

Maximum:

2 pages.

Never leave huge white empty areas.

Compress sections elegantly.
